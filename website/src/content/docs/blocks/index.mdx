These are Flutter **host source**, not additional package widgets or a runtime you
must install. All demo records and money are synthetic.

## Components, patterns, guides and blocks

| Section | Use it to |
| --- | --- |
| [Components](/components/) | Choose a widget and understand its supported props and states |
| [Patterns](/patterns/checkout/) | Understand domain composition, financial invariants and host responsibilities |
| [Guides](/patterns/views-and-pages/) | Solve general layout, forms and loading/empty/error presentation |
| Blocks | Copy a full host composition and run a mobile demo |

A block can use several patterns. Domain rules stay in their pattern pages;
block pages link to them and explain adoption. General guides keep their existing
`/patterns/…` URLs so bookmarks remain valid.

## Adoption order

1. Install the [package](/start/installation/) and configure shared theme tokens.
2. Copy the block source and supply your host models and callbacks.
3. Apply a scoped family theme when the product needs a shared component look.
4. Use a named host preset for a repeated subset, then an inline override only
   for a justified exception. See [theming](/concepts/theming/).

You own auth, networking, durable attempt persistence, quotes and status verdicts,
plus routing and platform effects. Demo adapters are not production integrations.
Copying source does not establish payment-provider compliance or production readiness.

## Roadmap and references

The [Payment/KYC block tracker #223](https://github.com/naufaldi/flutter_ui_payment/issues/223)
tracks the Payment/KYC block set. Every block in the table above is shipped and
runnable; open issues there describe planned work, not additional shipped blocks.

We use [shadcn Blocks](https://ui.shadcn.com/blocks) as a reference for visible
preview/source/file composition, [Flutter Templates Finance](https://www.fluttertemplates.dev/widgets/finance/)
for mobile screen categories, and [FlockUI](https://www.flockui.com/) for direct
ownership of copied Dart source. We adapt those presentation ideas to this kit's
mobile and host-ownership rules. No third-party code, assets, desktop dashboard
layout or financial behavior is imported.
