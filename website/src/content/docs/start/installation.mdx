Install `rakit_ui` 0.1.0 from [pub.dev](https://pub.dev/packages/rakit_ui).

## Requirements

- Dart `^3.12.0` and Flutter `>=3.44.0`. Tested with Flutter 3.44.6 stable.
- The only dependency is the Flutter SDK. The package adds no network, analytics, media, camera, ad or payment SDK.
- `flutter_localizations` from the Flutter SDK, for the Material and Cupertino delegates you register next to `PaymentLocalizations.delegate`.

## Install from pub.dev

```sh
flutter pub add rakit_ui
```

Include the Flutter localization delegates when using the quick start:

```yaml title="pubspec.yaml"
dependencies:
  flutter:
    sdk: flutter
  flutter_localizations:
    sdk: flutter
  rakit_ui: ^0.1.0
```

## Development: path dependency

Use this when the package sits next to your app on disk, for example while evaluating it.

```yaml title="pubspec.yaml"
dependencies:
  flutter:
    sdk: flutter
  flutter_localizations:
    sdk: flutter
  rakit_ui:
    path: ../flutter-ui-payment
```

Then fetch packages:

```sh
flutter pub get
```

## Migrating from flutter_ui_payment

Rakit UI continues the same UI kit under the `rakit_ui` package name. Replace the old dependency and update imports:

```yaml
dependencies:
  rakit_ui: ^0.1.0
```

```dart
import 'package:rakit_ui/rakit_ui.dart';
```

Remove `flutter_ui_payment` from your dependencies, then run `flutter pub get`. Widget names, theme APIs, models and host callbacks are unchanged. Replace private `package:flutter_ui_payment/src/...` imports with the public Rakit UI API where possible.

The old package and its published versions remain available for existing apps. Use one package identity throughout an app: types from the two separately published packages are distinct. The compatibility filename `package:rakit_ui/flutter_ui_payment.dart` forwards to the new library, but does not redirect old-package imports.

## Import

Everything is exported from one library:

```dart
import 'package:rakit_ui/rakit_ui.dart';
```

## Optional: video

`PaymentVideoPlayer` needs a media engine, and the package ships none. If you use it, add a player such as the official `video_player` plugin to your app and adapt it (see [Media](/components/media/)). The example app uses:

```yaml title="pubspec.yaml"
dependencies:
  video_player: ^2.11.1 # Android minSdk 24, iOS 13
```
