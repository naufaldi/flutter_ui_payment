`KycCaptureGuide` composes framing, tips, photo review, upload progress and host rejection messages. `CaptureFrameOverlay` can sit over a host camera preview. Neither widget reads or judges the image.

<HostOwns>camera, permission, photo bytes, upload, safe rejection reasons and every verdict. No OCR, liveness, face matching or photo scoring is performed.</HostOwns>

The [KYC capture and upload recovery block](/blocks/kyc-capture/) runs this guide in a mobile host screen with permission, quality and upload recovery and stale-upload protection.

## Usage

The flow is onPick → source sheet → host permission → guide or OS picker. The example keeps photo bytes in the capture screen's local state, with synthetic fixtures only.

```dart
final source = await showCaptureSourceSheet(context: context);
if (source == null || !context.mounted) return;
if (source != CaptureSource.file) {
  final allowed = await c.requestCapture(req.key);
  if (!allowed || !context.mounted) return;
}
if (source == CaptureSource.camera) {
  await Navigator.of(context).push(MaterialPageRoute<void>(
    builder: (_) => KycCaptureScreen(
      c: c, requirement: req,
      kind: req.key == selfieSlot ? CaptureKind.selfieWithIdCard : CaptureKind.idCard,
    ),
  ));
  return;
}
// Host opens its gallery or file picker here.
```

```dart
KycCaptureGuide(
  kind: CaptureKind.idCard,
  state: slot,
  photo: hostPhoto,
  preview: hostPreview,
  onCapture: capture,
  onUsePhoto: upload,
  onRetake: retake,
);
```

## In a screen vs in a scroll view

Place `KycCaptureGuide` directly in a bounded screen body to pin Take photo, Use photo and Retake in the bottom safe area. The preview fits above the footer in a centred column at most 640 dp wide, using up to half the body height at normal text and a quarter at large text. Status, banners and guidance share a scroll region below a preview that is at least 96 dp high. Long status copy can scroll on short screens. The footer has one primary action and at most one quiet secondary action.

Inside a host scroll view, the guide keeps its inline preview and action `Wrap`, as in the gallery. No signature change is needed; remove a host scroll wrapper to opt into the screen layout. Hosts that use intrinsic-sizing parents (`IntrinsicHeight`, `SliverFillRemaining(hasScrollBody: false)`) must wrap the guide in a scroll view or use a bounded body instead.

## States and variants

Framing offers Take photo, with Open settings when the host allows it. A local photo offers Use photo and Retake. Uploading and uploaded states offer Retake. An interrupted upload offers Try again and Retake. A host rejection shows its safe reason and Retake when permitted. Permanent permission denial offers Open settings.

## Content guidelines

Tips describe framing only. Uploaded means the host finished uploading, never that identity was checked. Pass only safe host messages. Do not use real KTP images in demos. Mask NIK using `PrivacyMask` or draw it masked. The card uses the ID-1 ratio of 85.6 × 54; the selfie keeps the card below the chin.

## Accessibility

The frame has a kind-specific label and ignores pointer events so the host preview receives gestures. Tips wrap at large text. Rejection notices announce their host message. The preview scrim uses black and a white outline to remain visible over arbitrary camera content.

## Capture source sheet

`showCaptureSourceSheet` reports the source the customer chose. It opens no device source itself.

<HostOwns>available sources, permission, OS picker, camera, and opening settings.</HostOwns>

<Screens><Screen name="android_catalog_capture_source_sheet" dark="android_catalog_capture_source_sheet_dark" alt="Add a photo sheet offering camera, gallery and file sources." caption="Source choice before permission" /></Screens>

### Usage

```dart
final source = await showCaptureSourceSheet(
  context: context,
  sources: {CaptureSource.camera, CaptureSource.file},
  unavailable: {CaptureSource.camera: 'Camera access is off'},
  onOpenSettings: openHostSettings,
);
```

### States and variants

Rows always appear camera, gallery, file. Blocked rows show the host reason. Close, dismissal and Open settings return null. Skip the sheet when only one source is offered. The source set must be non-empty.

### Content guidelines

Describe permission availability in plain language. Offer only sources the host supports. Ask permission after the customer chooses a source.

### Accessibility

Action rows have full touch targets and disabled reasons. The sheet uses the existing close button, focus and dismissal behavior.
