## Choose a chart

| Question | Component | Watch out for |
| --- | --- | --- |
| Going up or down? | Line | A zoomed axis emphasizes change, so read the tick labels. |
| How much each? | Bar | Starts at zero; small differences may disappear. |
| Breakdown of a total? | Meter | One snapshot, up to five categories. |
| Quick trend? | Sparkline | No precise values or axes. |

## Usage

The container owns height: 180 for compact plots, 320 for featured plots. Meter charts use intrinsic height. Show the host headline first. At most three plots belong in one row, each around 200px or wider; stack them on phones.

```dart
Row(children: [
  Expanded(child: ChartModule(
    title: 'Weekly spending',
    state: ChartState.ready,
    headline: const Money.idr(1080000),
    headlineCaption: 'Settled',
    chart: PaymentBarChart(points: weeklyPoints),
  )),
  const SizedBox(width: 16),
  Expanded(child: ChartModule(
    title: 'Trend',
    state: ChartState.ready,
    chart: PaymentLineChart(points: weeklyPoints),
  )),
]);
```

## States

Choose loading before error, error before empty, then ready. `ChartModule` keeps the plot height stable across these states; the headline is outside the plot. Error and empty messages scroll at large text so the retry action remains reachable.

## Reading the exact amount

Line and bar charts show one exact value at rest: the latest settled period is selected, with a guide line up to a label above the plot ("29 Okt · Rp420.000"). Tap or drag to read another period (D58). The y-axis gutter grows with its scaled labels, so "Rp600K" never touches the plot at 200%. Above 1.5× text the module caps the plot at `ChartModule.compactHeight`, so the rows under a chart stay on the first screen of a small phone.

## The payment boundary

Pending uses dashed/outlined marks. Unknown uses dotted/hatched marks. Missing data leaves a gap. Only settled values enter the generated lowest/highest/latest summary. Headlines are host-provided Money values; the kit never computes totals. The meter legend formats the selected unit: money, percent or number.

## Content guidelines

Give periods short labels and qualify a headline as settled when needed. Keep currencies consistent. Use compact formatting for axes only, never a payment confirmation.

## Accessibility

The chart summary announces the same latest amount the label shows, so nothing depends on selection. At narrow widths, fewer visual axis labels preserve space. Supply a complete `semanticLabel` when your host needs additional context.

## Comparing periods

The headline region derives from the scaled amount line, caption line and section gap. Named series share period labels and one scale:

```dart
PaymentLineChart(series: const [
  PaymentChartSeries(label: 'This month', points: [
    ChartPoint(label: 'Week 1', value: Money.idr(350000)),
  ]),
  PaymentChartSeries(label: 'Last month', points: [
    ChartPoint(label: 'Week 1', value: Money.idr(280000)),
  ]),
]);
```
