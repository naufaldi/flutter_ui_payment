Use semantic tokens from the kit. Never invent raw colors, sizes or weights.

`PaymentType.of(context)` exposes nine roles. Every role inherits the host font from textTheme.bodyMedium; the kit bundles no fonts. Values below show size, line, weight and tracking.

```text
One display amount? → display
Action-bar total or balance? → amountLarge
Sheet/dialog title? → title
Section/status title or button? → heading
Paragraph? → bodyFor(context)
Row label/value? → label
Supporting line? → caption
Short status? → tag
Field entry? → input
```

## Modifiers

Use `type.tabular(style)` for changing or aligned numbers. Use `type.reference(style)` for VA numbers, transaction IDs and promo codes: it adds tabular figures in the host reference font (Menlo, monospace, Courier fallback). PaymentType has no weight modifier; choose heading instead of label for hierarchy. Hosts may set amountWeight, amountFontFamily and referenceFontFamily.

Do: `PaymentType.of(context).caption`, as the existing rows do. Don't: `TextStyle(fontSize: 13)`, which loses host font and semantic intent.

```dart
final type = PaymentType.of(context);
final rowAmount = type.tabular(type.label);
final reference = type.reference(type.label);
SizedBox(
  height: PaymentType.firstLineHeight(context),
  child: const Center(child: Icon(PaymentIcons.info)),
);
```

Above 1.5×, rows wrap values and bodyFor uses 1.3 leading. At 200%, titles still wrap. Amounts at 20 and above and adjacent medium icons clamp at 1.6×; amounts scale down rather than hide digits. Use sentence case, specific copy and put key words first. Never truncate an action label.

## Stripe mapping

| Stripe font | PaymentTextRole |
| --- | --- |
| title | title |
| subtitle, heading, subheading | heading |
| lead, body | body |
| bodyEmphasized | body + semibold |
| caption | caption |
| kicker | tag |

PaymentFontWeight is regular (400), semibold (600), bold (700). Bold is only for emphasis inside running text. **New** `PaymentInline` is its planned consumer. This does not add a tenth role. Nothing else exists.

## Migration

`theme.amountStyle(context)` remains the display alias. The deprecated large parameter becomes `type.tabular(type.label)` for row amounts; choose `type.tabular(type.heading)` only when preserving the old 600 weight is required.
