Use semantic tokens from the kit. Never invent raw colors, sizes or weights.

Which text color:

```
Is the control disabled?            → disabled
Is it a status word or status icon? → tone(t).foreground
Is it on an accent fill?            → onAccent
Is it a label, caption or muted icon? → textSecondary
Default                             → textPrimary
```

Which line:

```
Is the line how someone finds a control (input, secondary button, unchecked box)? → border (≥ 3:1)
Is it the selected or focused edge?  → accent (selected) / textPrimary ring (focus, §3.8)
Default (separates content only)     → outline (may be < 3:1)
```

Values are exported from the real Hairline theme in `example/lib/themes.dart`, in both brightness modes. Hosts override tokens through `PaymentTheme.copyWith`. Tone containers mix foreground toward surface by 90% in light mode and 84% in dark mode. Neutral follows the host scheme. Text must reach 4.5:1, control edges and meaningful marks 3:1. Decorative rules may recede below 3:1.

## Do and don't

Do: `theme.border` on an input edge, as in the existing controls. Don't: `theme.outline` for that edge; it cannot identify a control at 3:1.

## Raw-color exceptions

Camera overlay: `capture_widgets.dart:116,158` uses black54 and white over a host preview. Video controls/scrim: `video.dart:282,296,301,312,315,326,365` uses white70, white, black54 and black over imagery. Side sheet: `sheets.dart:192` uses black54 as its barrier. Transparent focus/surface tint entries remove Material fill rather than define a new color. No other raw-color styling is admitted.

The toast still uses Material SnackBar background defaults. D22 schedules its token restyle in 2C; this page does not claim that gap is fixed.
