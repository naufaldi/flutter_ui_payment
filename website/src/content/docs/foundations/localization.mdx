The kit ships two languages: English (`en`) and Indonesian (`id`). Every widget reads its strings from `PaymentLocalizations`.

## Register the delegate

```dart
MaterialApp(
  localizationsDelegates: const [
    PaymentLocalizations.delegate,
    GlobalMaterialLocalizations.delegate,
    GlobalWidgetsLocalizations.delegate,
    GlobalCupertinoLocalizations.delegate,
  ],
  supportedLocales: const [Locale('id'), Locale('en')],
);
```

The `Global…` delegates come from `flutter_localizations` (add it to your `pubspec.yaml`). Without `PaymentLocalizations.delegate`, widgets still pick a language from the ambient locale: Indonesian for `id`, English otherwise. `PaymentLocalizations.supportedLanguages` is `['en', 'id']`.

The strings for the interaction, navigation, sheet, media, promotion and transaction components live in the `KitStrings` extension on `PaymentLocalizations`, so you keep one delegate.

## Money

Amounts follow the language too: `id` groups with `.` and uses `,` for decimals, `en` does the opposite. `PaymentLocalizations.of(context).moneyFormat` is the active `MoneyFormat`. [Money](/foundations/money/) covers the type, formatting, currencies and strict parsing.

## Dates

`PaymentLocalizations.formatDateTime` prints "30 Oct 2026, 14:05" in English and "30 Okt 2026, 14.05" in Indonesian, in the device time zone.

Use semantic formatting APIs only. Choose en or id; no third locale exists. Nothing else exists.

| You are showing… | Use |
| --- | --- |
| A calendar date | `formatDate` |
| An instant | `formatDateTime` |
| An amount | `moneyFormat` |
| The kit's built-in words | `PaymentLocalizations` / `KitStrings` |

Do: register the existing localization delegates above. Don't: hardcode translated strings in a widget. See [Money and dates](/foundations/money/#dates) for calendar formatting and typed-date pattern overrides.

## Field foundation

New field strings include invalid-date, calendar, optional, character counter and currency labels. Indonesian Material calendar labels require GlobalMaterialLocalizations.delegate in the host.
