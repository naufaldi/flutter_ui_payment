Use semantic tokens from the kit. Never invent raw colors, sizes or weights.

The scale is **4 / 8 / 12 / 16 / 24 / 32** on the 8 base: an 8 pt grid with 4 pt half-steps, so `block` (12) is on the grid (D46). Every kit spacing value resolves through `theme.space(PaymentSpace.<role>)`, and **one role uses one value**: icon → text is always `block` (12) — in the toast, banner, state message, accordion, skeleton, list row and status header alike.

```text
No gap? → none
Within one label? → inline
Related rows/actions? → related
Icon beside row text or row padding? → block
Gutter or label/value gap? → group
Before primary action or ruled section? → section
Largest reserved gap? → major
```

## Component sizes

Heights and boxes are component sizes, not spacing roles, so they are not `PaymentSpace` values. They sit on the 4 grid: **36** (small button, `InfoRow` pitch), **40** (media tile), **48** (minimum target, list row, small field), **52**, **56** (medium field, large button), **60** (video play disc) and **64** (large list row, large field). A two-line list row is 62 dp (12 + 20 + 18 + 12): its parts are on the grid, and the loading skeleton copies it. Values that are not multiples of 4 (such as 7) are not used.

## Stripe mapping

| Stripe size | PaymentSpace |
| --- | --- |
| xxsmall | inline |
| xsmall | related |
| small | block |
| medium | group |
| large | section |
| xlarge, xxlarge | major |

| Stripe radius | PaymentRadius |
| --- | --- |
| none | none |
| xsmall | tag |
| small | control |
| medium | box |
| large | sheet |
| rounded | circle |

Use theme.space to preserve the host base unit. The default gutter is 16 at every width. Nested radii must be concentric: inner rounding is smaller than outer rounding. Sections stay flat and separated by space.

Do: `EdgeInsets.all(theme.space(PaymentSpace.group))`, the named version of existing screen gutters. Don't: `EdgeInsets.all(16)`.

```dart
final theme = PaymentTheme.of(context);
final gutter = EdgeInsets.all(theme.space(PaymentSpace.group));
```

Size is small, medium (default), large; width is fill (default) or hug. All labels wrap. Their **New** component consumers arrive later; every layout/hit box remains at least 48×48 dp regardless of visual size. **New** `PaymentBox` is not implemented. Nothing else exists.
