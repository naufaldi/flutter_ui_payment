Use Flutter SDK Material icons with `PaymentIcon` for semantic sizes and colors. Keep one icon family across kit content.

| The icon sits… | Size |
| --- | --- |
| Inside a badge | `xsmall` |
| In a compact slot | `small` |
| Beside 15/20 text | `medium`, centered on the first line |
| In a state illustration | `large` |
| In a privacy mask | `xlarge` |

| `PaymentIconSize` (Stripe) | Size | Use for | Color |
| --- | --- | --- | --- |
| `xsmall` (12) | 14 | Inside a badge (`primitives.dart:531`) or chip. 14, not 12, is the kit's smallest icon | Tone `foreground` |
| `small` (16) | 16 | Merchant verification mark (`payment_extras.dart:237`) and compact slots | Label color |
| `medium` (20), default | 20, scales with text up to 1.6×, first-line centered | Beside 15/20 text: row leading, button icon, banner, status header, state message, chevron, close, copy | `textSecondary`; tone `foreground` for status; `accent` only for an icon that is the action itself (copy) |
| `large` (32) | 32 | Video control (`video.dart:281`) and state illustrations | `textSecondary` |
| `xlarge` (64) | 48 | `PrivacyMask` (`primitives.dart:844`) | `textSecondary` |
| — | 32 / 36 | Video overlay only (`video.dart:281, 325`); documented media exception | `Colors.white` on scrim |

Pair icons with adjacent words or an accessible label or tooltip. Status combines color, icon and text. The kit uses outlined icons, with fixed control glyphs such as `copy_rounded`, `warning_amber_outlined` and `hourglass_top_outlined`. Media controls use `play_arrow`, `pause` and `replay`.

Use `Icons.chevron_right` and let the SDK's `matchTextDirection` handle RTL. Manually swapping to `chevron_left` as well can reverse the direction twice.

## Payment pattern mappings

Transaction status maps pending→schedule, unknown→help_outline, requiresAction→touch_app_outlined, processing→sync, succeeded→check_circle_outline, failed→error_outline, canceled→block, expired→timer_off_outlined (`payment/transactions.dart:80–95`). Payment status adds submission sending→sync and outcomeUnknown or missing snapshot→help_outline; refund none→remove, pending→schedule, partial→call_split, refunded→undo, failed→error_outline (`payment_status.dart`, _StatusLook and refund switch). These remain Tier 2 mappings, not extra foundation meanings.

Choose from the documented sizes and meanings to keep icons consistent across screens.

## Layout foundation

PaymentIcon owns token size, color and first-line alignment. Fixed control glyphs remain inside buttons, badges, spinners, field messages, switches, toasts and video scrims.
