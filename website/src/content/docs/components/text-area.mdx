## Stripe → kit

| Stripe | Kit |
| --- | --- |
| rows | minLines / maxLines |
| resizeable | maxLines: null |
| onChange | onChanged |

minLines and maxLines replace rows. maxLines null allows growth. Enter inserts a newline; Command or Control plus Enter submits. A character counter announces remaining space near the limit. cols, wrap, spellCheck, autoComplete and css width are not mirrored.

## Variants

Variants: small, medium, large; multiline. Nothing else exists.

## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| Problem description | medium | Keep the privacy instruction visible and cap reports at 500 characters. |

Use Text field for a short single-line value.

## States

Default, focused, disabled and error. Errors include an icon, text and an edge. Selection controls support hardware keyboards.

## Do and don't

**Do**: Keep the privacy instruction visible and cap reports at 500 characters.

**Don't**: Log free text or send the report draft to analytics.

## Content guidelines

Use short, specific labels and explain how to correct an error.

Keep the privacy instruction visible and cap reports at 500 characters.

## Accessibility

Input text is 16 dp. Legends precede fields in reading order. Labels and errors stay in semantics when visually hidden. Pickers restore focus.

The report example never logs free text. Only category and character count cross the host boundary; the controller is disposed on close.
