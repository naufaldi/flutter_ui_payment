## Usage

```dart
// example/lib/screens/gallery_content.dart
PaymentTaskList(
          items: [
            PaymentTaskListItem(
              title: 'Identity',
              status: PaymentTaskStatus.complete,
            ),
            PaymentTaskListItem(
              title: 'Documents',
              status: PaymentTaskStatus.inProgress,
              subTasks: [
                PaymentTaskListItem(
                  title: 'KTP',
                  status: PaymentTaskStatus.complete,
                ),
                PaymentTaskListItem(title: 'Selfie'),
              ],
            ),
            PaymentTaskListItem(
              title: 'Review',
              status: PaymentTaskStatus.blocked,
            ),
          ],
        );
```

## Variants

Variants: notStarted, inProgress, blocked, complete.

### The connector

A thin line joins each top-level task's mark to the next. It says only that the tasks run in this order. It looks the same whatever the status, so read progress from the marks and their spoken status, never from the line. Sub-tasks have no connector.

### States and content

Show the host-defined task sequence. A blocked task needs a reason and a permitted next action; complete tasks hide their children.

## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| KYC progress | inProgress | The host decides status; completed steps may offer edit actions. |

Use Step indicator for a short linear merchant checkout sequence.

## States

The host sets `notStarted`, `inProgress`, `blocked` or `complete`. Completing a task hides its child tasks; upload completion alone does not verify identity.

## Do and don't

**Do**: The host decides status; completed steps may offer edit actions.

**Don't**: Mark a task complete just because its widget mounted.

## Content guidelines

Use task names such as "Your details" and "ID photo". Put the correction needed in the blocked reason, not just "Error".

## Accessibility

Marks and spoken status distinguish tasks without relying on color. Completed tasks hide their children.
