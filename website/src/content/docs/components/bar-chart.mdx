## Usage

```dart
PaymentBarChart(points: const [
  ChartPoint(label: 'Week 1', value: Money.idr(350000)),
  ChartPoint(label: 'Week 2', value: Money.idr(450000), status: ChartPointStatus.pending),
]);
```

Wrap in `ChartModule` or a `SizedBox(height: 180)` with a bounded height. Use 320 for a featured plot. Below 200px, y labels are hidden and only the first and last x labels remain.

## States and variants

Settled marks are solid, pending marks are outlined or dashed, and unknown marks are hatched or dotted. A null point is a gap, never zero. Use one currency per chart. Bar and meter amounts must be non-negative; line charts accept negative amounts.

## Content guidelines

Use short period labels and a clear title. Explain what is settled in the headline caption. The host supplies the headline; the kit never adds plotted values to produce a customer total.

## Accessibility

A single generated summary announces settled lowest, highest and latest amounts plus pending, unknown and missing counts. Supply `semanticLabel` for a host-authored equivalent. Pointer inspection on line/bar charts is supplemental; it has no keyboard focus target. Status is conveyed by shape and words as well as color.

## Series, axes and units

Use named series with identical period labels and ordering. Line and bar charts accept up to three series; sparklines accept two. Series use an accent ramp and distinct dash patterns, never status tones. All series share a scale. `showLegend` controls the legend for multiple series.

| Stripe | Kit |
| --- | --- |
| x / y | `axis` and `grid`: x, y, both or none |
| color / z | Named `PaymentChartSeries` |
| format / tickFormat / unitFormat | `unit`: money, percent or number |
| legend | `showLegend` |

Use a line for direction, bars for period comparisons, a meter for category proportions and a sparkline beside a KPI. Percent and number units read `measure`; money reads `value`. A measure of 45 means 45 percent. Missing readings remain gaps.

Sparklines can opt into `inspectable`, giving a 48 dp target. Press and hold to read a value. Meter `onSegmentPressed` activates full-width legend rows; the painted bar takes no taps.

**Breaking:** `MeterSegment.color` is removed. Use the semantic category ramp. `MeterSegment.value` is optional; supply `measure` for numeric units. Point `value` and chart `points` are optional when using measures or series.
