## Usage

```dart
PaymentMeterChart(segments: [
  MeterSegment(label: 'QRIS', value: const Money.idr(350000)),
  MeterSegment(label: 'Transfer', value: const Money.idr(450000)),
]);
```

Use intrinsic height (`ChartModule(height: null)`) so the wrapping legend has room. Offer at most five categories; group the rest into “Other”. Segment widths use the supplied amounts, while the legend shows amounts, never percentages.

## States and variants

Settled marks are solid, pending marks are outlined or dashed, and unknown marks are hatched or dotted. A null point is a gap, never zero. Use one currency per chart. Bar and meter amounts must be non-negative; line charts accept negative amounts.

## Content guidelines

Use short period labels and a clear title. Explain what is settled in the headline caption. The host supplies the headline; the kit never adds plotted values to produce a customer total.

## Accessibility

A single generated summary announces settled lowest, highest and latest amounts plus pending, unknown and missing counts. Supply `semanticLabel` for a host-authored equivalent. Pointer inspection on line/bar charts is supplemental; it has no keyboard focus target. Status is conveyed by shape and words as well as color.
