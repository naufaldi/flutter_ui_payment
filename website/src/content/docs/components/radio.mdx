## Usage

```dart
// example/lib/screens/gallery_selection.dart
PaymentRadio(
                value: method,
                groupValue: null,
                onChanged: (_) {},
                label: method,
                errorText: 'Choose how to get your receipt',
              );
```

## Variants

Variants: selected, unselected. Nothing else exists.

### Selected

The selected option is a 6 px ring in the accent color; the others are a 1.5 px ring in `textSecondary`. The difference is in the shape, so it does not rely on color. Choosing the selected option again does nothing.

### Disabled

Pass `onChanged: null` to one option. Its ring uses the `disabled` color and its label turns muted. Pass `disabledReason` so people know why; it replaces `description` while the option is disabled.

### Pattern adoption

The payment method picker shares the same radio mark. An unavailable method has a thin 1.5 dp disabled ring, a muted label and an explicit unavailable reason. The selected mark has a 6 dp accent ring. There is no block glyph.

### Behavior, states and migration

Stripe error maps to errorText: icon, danger caption and unchecked danger ring. Required is semantics-only; hosts own validation and progression. HiddenElements keeps hidden label, description and error text spoken. Keep a group's labels visible when they distinguish choices, and use specific recovery copy.

## States

Host state is explicit. Loading does not imply success; disabled actions retain a readable explanation. Interactive controls retain focus and pressed feedback.

## Do and don't

**Do**: Use one groupValue for mutually exclusive options; choosing the selected row is a no-op.

**Don't**: Allow multiple default methods in one radio group.

## Content guidelines

- Title the group with the question or the setting: "Send receipt by".
- Keep option labels short and parallel: "Email", "SMS", "Don't send".
- Preselect the safest or most common option, and offer an explicit "none" option rather than leaving the group empty.
- For more options than fit on screen, use a list on its own screen or sheet.
- Payment methods have their own picker with unavailable reasons: use `PaymentMethodPicker` from [Checkout](/patterns/checkout/).

Use one groupValue for mutually exclusive options; choosing the selected row is a no-op.

## Accessibility

- Each option is one row of at least 48 dp and one screen-reader node, announced as checked or not checked in a group of mutually exclusive options.
- The selected option stays in the focus order, so Tab reaches every option. Keyboard focus draws the kit's [focus ring](/foundations/focus/).
