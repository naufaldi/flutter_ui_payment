A 48 dp icon action needs a nonempty tooltip. Neutral uses secondary text; accent marks a primary value affordance. Keyboard focus draws a circular ring and presses scale to 0.96. Disabled uses the disabled token. Use a labeled button when the glyph cannot explain the action. Variants: neutral, accent.

## Usage

```dart
// example/lib/screens/gallery_selection.dart
PaymentIconButton(
            icon: PaymentIcons.close,
            tooltip: 'Close',
            onPressed: () {},
          );
```

## Variants

Variants: neutral, accent.

## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| Fee policy help | neutral | Always provide a tooltip; use accent only for the selected or emphasized action. |

Use Button when a word is needed to explain the action.

## States

A null callback disables the action. Keep its tooltip specific enough to identify the action without relying on the glyph.

## Do and don't

**Do**: Always provide a tooltip; use accent only for the selected or emphasized action.

**Don't**: Ship an unlabeled icon-only control.

## Content guidelines

Use a tooltip that names the action, such as "Copy reference". Use a labeled button when the icon needs an explanation.

## Accessibility

Targets are at least 48 dp. Tooltips name icon actions. Links announce their role and external destinations. Copy feedback uses a live region and a check rather than color alone.
