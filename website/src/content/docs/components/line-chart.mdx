## Variants

Variants: one to three series, money, percentage, number. Nothing else exists.

### States and variants

Settled marks are solid, pending marks are outlined or dashed, and unknown marks are hatched or dotted. A null point is a gap, never zero. Use one currency per chart. Bar and meter amounts must be non-negative; line charts accept negative amounts.

### Series, axes and units

Use named series with identical period labels and ordering. Line and bar charts accept up to three series; sparklines accept two. Series use an accent ramp and distinct dash patterns, never status tones. All series share a scale. `showLegend` controls the legend for multiple series.

| Stripe | Kit |
| --- | --- |
| x / y | `axis` and `grid`: x, y, both or none |
| color / z | Named `PaymentChartSeries` |
| format / tickFormat / unitFormat | `unit`: money, percent or number |
| legend | `showLegend` |

Use a line for direction, bars for period comparisons, a meter for category proportions and a sparkline beside a KPI. Percent and number units read `measure`; money reads `value`. A measure of 45 means 45 percent. Missing readings remain gaps.

### Exact value at rest (D58)

The latest settled period is selected when the chart appears. One label in a fixed band above the plot gives its exact amount, such as "29 Okt · Rp420.000" in tabular figures, and a guide line runs from the point or bar top up to that label. Tap a period, drag across the plot or hover with a mouse to select another; moving the mouse away returns to the latest. The band never changes height, so nothing below the chart moves. A multi-series chart gives each series one line, "29 Okt · Bulan ini · Rp420.000". When any period's series name and value don't fit on one line, as at 200% text on a phone or for a pending period's longer value, every series shows its name with the value under it, and the name wraps to a second line instead of being cut. Inside `ChartModule` the plot area grows by those extra lines, so the plot keeps its height. With `inspectable: false` the label still shows the latest value and the chart takes no gestures. Series of 12 points or fewer draw a small ring on every settled point; longer series ring the last point. There is no permanent label on every point: those collide at 200% text and in Indonesian.

Sparklines can opt into `inspectable`, giving a 48 dp target. Press and hold to read a value. Meter `onSegmentPressed` activates full-width legend rows; the painted bar takes no taps.

**Breaking:** `MeterSegment.color` is removed. Use the semantic category ramp. `MeterSegment.value` is optional; supply `measure` for numeric units. Point `value` and chart `points` are optional when using measures or series.

## States

Host state is explicit. Loading does not imply success; disabled actions retain a readable explanation. Interactive controls retain focus and pressed feedback.

## Do and don't

**Do**: Use an explicitly labeled timeline; add series only for a real comparison.

**Don't**: Hide missing data by inserting zero.

## Content guidelines

Use short period labels and a clear title. Explain what is settled in the headline caption. The host supplies the headline; the kit never adds plotted values to produce a customer total.

Use an explicitly labeled timeline; add series only for a real comparison.

## Accessibility

A single generated summary announces settled lowest, highest and latest amounts plus pending, unknown and missing counts. Supply `semanticLabel` for a host-authored equivalent. The value label is supplemental: the summary already announces the latest amount, and selection has no keyboard focus target. Status is conveyed by shape and words as well as color.
