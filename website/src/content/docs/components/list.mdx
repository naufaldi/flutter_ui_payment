`PaymentListItem` is a tappable row for settings, menus and action lists: an outlined icon, a title and a muted detail line, with no box around it.

## Usage

```dart
// example/lib/screens/flow_screen.dart
PaymentList(
            children: [
              PaymentListItem(
                icon: Icons.receipt_long_outlined,
                title: s.transactions,
                onPressed: c.openHistory,
              ),
              PaymentListItem(
                icon: Icons.description_outlined,
                title: s.statement,
                onPressed: c.openStatement,
              ),
              PaymentListItem(
                icon: Icons.sell_outlined,
                title: s.fees,
                onPressed: c.openFees,
              ),
              PaymentListItem(
                icon: Icons.settings_outlined,
                title: s.accountSettings,
                onPressed: c.openAccountSettings,
              ),
            ],
          );
```

## Variants

Variants: standard, large. Nothing else exists.

### Default

With `onTap`, the row shows a chevron at the end (mirrored in right-to-left languages). Pass `trailing` to put your own widget there instead, such as a value or a 48 dp button; it keeps its own size.

### Disabled

A row without `onTap` is disabled. It stays visible with a muted title, but it is not focusable. Pass `disabledReason`; it replaces the subtitle so people know why they cannot use the row.

### Destructive

`destructive: true` draws the icon and title in the danger tone. Color is never the only signal: the title must already say what happens, such as "Sign out of all devices". Confirm the action with a [dialog](/components/dialog/) before you run it.

```dart
PaymentListItem(
  icon: Icons.logout,
  title: 'Sign out of all devices',
  destructive: true,
  onPressed: confirmSignOut,
);
```

### Variants, behavior and migration

Stripe List/ListItem map to PaymentList/PaymentListItem. Standard uses a 48 dp minimum and label title; large uses 64 dp and heading. Variants: size, value, icon, destructive, disabledReason and trailing. Nothing else exists. Read-only rows keep ink titles without a button role; disabled rows explain why. Do not put selection controls in value or trailing; use their dedicated rows. Values align to the first line before the navigation chevron.

PaymentList.onAction receives a row id unless its own onPressed overrides it. No handler and no reason means read-only. The forward glyph mirrors once in RTL.

Migration: ActionTile remains a wrapper until 0.2.0. Rename subtitle to secondaryTitle and onTap to onPressed. ActionTileGroup is a deprecated PaymentList alias.

### Layout foundation

PaymentListItem accepts a PaymentImage in its image slot instead of an icon. Supply alt text for a bank logo.

## States

Host state is explicit. Loading does not imply success; disabled actions retain a readable explanation. Interactive controls retain focus and pressed feedback.

**Layout.** In a single-line row the title, value and trailing control share one centre line; in a multi-line row the icon and the trailing control centre on the title's first line (D56). Above 1.5× text the value moves under the title at label size instead of shrinking beside it. A two-line row is 62 dp; rows with a trailing action are at least 48 dp.

## Do and don't

**Do**: Use large for more descriptive rows; the whole action row is tappable.

**Don't**: Make a selection setting look like a navigation row.

## Content guidelines

- Titles name the destination or the action: "Transaction history", "Change PIN". Use sentence case and no end punctuation.
- Keep the subtitle to one short line of extra context, such as "Last 90 days".
- Write disabled reasons as the cause or the way out: "Managed by your bank app", "Verify your identity first".
- Use an icon on every row of a group or on none, so titles line up.

Use large for more descriptive rows; the whole action row is tappable.

## Accessibility

- Rows are at least 48 dp tall and announce as buttons; disabled rows announce as disabled.
- The icon and chevron center on the title's first line, so they stay beside the title when it wraps at large text. The icon grows with text up to 1.6×.
- Keyboard focus draws the kit's [focus ring](/foundations/focus/).
