## Usage

```dart
PaymentSection(
  title: 'Payment details',
  trailing: TextButton(onPressed: editDetails, child: const Text('Edit')),
  child: Column(
    crossAxisAlignment: CrossAxisAlignment.start,
    children: [
      const InfoRow(label: 'Amount', value: AmountText(Money.idr(102500))),
      InfoRow(label: 'Reference', valueText: attempt.attemptId),
      InfoRow(
        label: 'Pay before',
        value: CountdownText(expiresAt: va.expiresAt, clock: host.clock),
      ),
    ],
  ),
);

PaymentButton(
  label: 'Pay Rp102.500',
  busyLabel: 'Sending…',
  // Locks while the Future runs, so a double tap sends one callback.
  onPressed: () => host.submitPayment(attempt.attemptId),
);

const NoticeBanner(
  tone: StatusTone.warning,
  title: 'Total changed',
  message: 'Review the new total before you pay.',
  announce: true, // live region for screen readers
);
```

- `PaymentButton` has three variants (`primary`, `secondary`, `quiet`). While its callback's `Future` runs it shows a busy state and ignores more taps; this is interaction protection, not server-side deduplication. Full-width buttons are 48 dp and do not scale on press.
- `StatusBand` is solid for settled or waiting states and hatched (`hatched: true`) for an unknown outcome. `StatusHeader` puts an icon and title together; its icon grows with text up to 1.6×.
- `AmountText` formats through `MoneyFormat`, uses tabular figures, and scales down instead of clipping a digit.
- `InfoRow` keeps values up to 60% of the row; `MiddleEllipsisText` shortens long names in the middle (`ktp_demo_ret…ake.png`).
- `CountdownText` uses your host clock, stops at zero without going negative, and calls `onElapsed` once. Zero is not proof of non-payment.
- `PrivacyMask` covers content while `obscured` is true, for example in the app switcher. OS-level screenshot protection remains yours.
- `HostError` is what your adapter maps provider failures into: a `HostErrorCategory` plus an optional `safeMessage`.
