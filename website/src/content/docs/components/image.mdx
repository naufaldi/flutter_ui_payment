## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| Synthetic document preview | loaded | Pass a host ImageProvider and alt; empty alt means decorative. |

Use Icon for a symbolic status mark.

## States

The image fades in over its placeholder; instant under reduced motion.

The image preserves its loading surface and handles decode failure. It fades in when loaded, with no fade under reduced motion.

## Do and don't

**Do**: Pass a host ImageProvider and alt; empty alt means decorative.

**Don't**: Construct a network image in the kit.

## Content guidelines

Supply alt text that explains the image's purpose. Use an empty alt for decorative images.

## Accessibility

Meaningful images need alt text. Decorative images use an empty alt so they do not interrupt reading order.
