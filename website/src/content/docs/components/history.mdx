## Usage

```dart
TransactionHistory(
  records: TransactionRecord.where(all, query: query, filter: filter),
  query: query,
  filter: filter,
  loading: loading,
  error: loadError,
  onRetry: reload,
  onQueryChanged: (q) => setState(() => query = q),
  onFilterChanged: (f) => setState(() => filter = f),
  onOpen: (record) => showPaymentSheet<void>(
    context: context,
    builder: (_) => PaymentSheet(
      body: TransactionDetail(
        record: record,
        actions: [
          if (record.status == null || !record.status!.isTerminal)
            PaymentButton(
              label: 'Check status',
              onPressed: () => host.checkStatus(record.id),
            ),
        ],
      ),
    ),
  ),
);
```

`TransactionRecord.where` is a local search and filter for hosts that already hold the records (it matches title, merchant and reference). If you search on the server, pass your results straight to `records`.

## Behavior

- A record with `status: null` is "not confirmed yet". It falls under **In progress**, never **Unsuccessful**, and its detail should offer a status check, never paying again.
- Failed and canceled amounts are struck through; refunded amounts are not. Refunds appear as their own section next to the original payment.
- Filters are text tabs with a 2 px underline. Pending and unknown share the amber tag in the list and differ by icon and word; the hatched band appears only on the detail.
- `TransactionHistory` lays records out in a column. For long lists, build `TransactionListItem`s in a `ListView.builder` yourself.
