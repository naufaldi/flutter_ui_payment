## Usage

```dart
// example/lib/screens/gallery_forms.dart
PaymentDateField(
          label: 'Date of birth',
          value: DateTime(1995, 8, 17),
          onChanged: (_) {},
          firstDate: DateTime(1900),
          lastDate: DateTime(2030),
        );
```

## Stripe → kit

| Stripe | Kit |
| --- | --- |
| value / onChange | DateTime value / onChanged |
| format | app-wide dateInputPattern |
| disabled | enabled: false |

The app-wide date pattern is a hint and persistent caption. Separators are inserted without moving focus. Invalid input shows on blur or Form validation; correcting it clears the kit error. Host validators own age and range rules. The calendar is calendar-only. Indonesian calendar labels require the host to register GlobalMaterialLocalizations.delegate. No per-field pattern override exists.

## Variants

Variants: typed entry, calendar. Nothing else exists.

## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| KYC birth date | typed entry | Use host age/range validation; the app-wide pattern remains visible. |

Use Date range picker for a period.

## States

Default, focused, disabled and error. Errors include an icon, text and an edge. Selection controls support hardware keyboards.

## Do and don't

**Do**: Use host age/range validation; the app-wide pattern remains visible.

**Don't**: Use a hint as the only date-format instruction.

## Content guidelines

Use short, specific labels and explain how to correct an error.

Use host age/range validation; the app-wide pattern remains visible.

## Accessibility

Input text is 16 dp. Legends precede fields in reading order. Labels and errors stay in semantics when visually hidden. Pickers restore focus.
