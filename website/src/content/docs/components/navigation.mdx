## Usage

```dart
AdaptiveNavShell(
  title: const Text('Ruang Bayar'),
  selectedId: current,
  onSelected: (item) => setState(() => current = item.id),
  breakpoint: 840, // sidebar at or above this width, drawer below
  sections: const [
    PaymentNavSection(items: [
      PaymentNavItem(id: 'home', label: 'Home', icon: Icons.home_outlined),
      PaymentNavItem(
        id: 'history',
        label: 'History',
        icon: Icons.history,
        badge: '2',
      ),
      PaymentNavItem(
        id: 'limits',
        label: 'Limits',
        icon: Icons.speed,
        enabled: false,
        disabledReason: 'Verify first',
      ),
    ]),
  ],
  body: pages[current]!,
);
```

Use `NavSidebar` alone if you already have a shell.

## Behavior

- Selection is instant, with no animation, because navigation is used constantly. The selected item gets the selected color plus a muted fill.
- Disabled items are visible with their reason but not focusable.
- Opening the drawer moves focus into it. The scrim, Back and Escape close it, and focus returns to the menu button. Closed items are not in the focus order.

## Content guidelines

- Label destinations with short nouns: "Home", "History", "Limits". Use sentence case.
- Group items under a section title only when there are enough of them to need it.
- Keep a disabled item visible only when people can do something about it, and say what in `disabledReason`: "Verify first".
- Use `badge` for a count that needs attention, such as unread or pending items, not for marketing.
