## Usage

```dart
// example/lib/screens/gallery_screen.dart
AdaptiveNavShell(
      title: Text(s.tabGallery),
      sections: sections,
      selectedId: _section,
      onSelected: (item) => setState(() => _section = item.id),
      breakpoint: 720,
      actions: [
        IconButton(
          tooltip: s.settings,
          icon: const Icon(Icons.tune),
          onPressed: widget.onOpenSettings,
        ),
      ],
      body: ColoredBox(
        color: devWorkbench(context),
        child: SafeArea(
          // A new list per section so each one starts at the top.
          child: ListView(
            key: PageStorageKey('gallery-$_section'),
            padding: const EdgeInsets.fromLTRB(16, 8, 16, 32),
            children: [
              Center(
                child: ConstrainedBox(
                  constraints: const BoxConstraints(maxWidth: 640),
                  child: Column(
                    crossAxisAlignment: CrossAxisAlignment.stretch,
                    children: entries,
                  ),
                ),
              ),
            ],
          ),
        ),
      ),
    );
```

## Variants

Variants: sidebar, phone drawer.

### Behavior

- Selection is instant, with no animation, because navigation is used constantly. The selected item gets the accent color, heading weight, a muted fill and a 2 dp accent indicator on its start edge, so it never depends on the fill alone; in a dark theme whose accent matches the text, the fill is nearly invisible.
- Items are 48 dp apart.
- Disabled items are visible with their reason but not focusable.
- Opening the drawer moves focus into it. The scrim, Back and Escape close it, and focus returns to the menu button. Closed items are not in the focus order.

Use Tabs for alternate views of the same data.

## States

The host supplies the selected destination and handles changes. Disabled destinations stay visible with their reason.

## Do and don't

**Do**: Keep selected item and host destination synchronized; collapse when space breaks.

**Don't**: Add three levels of nested navigation for a short flow.

## Content guidelines

- Label destinations with short nouns: "Home", "History", "Limits". Use sentence case.
- Group items under a section title only when there are enough of them to need it.
- Keep a disabled item visible only when people can do something about it, and say what in `disabledReason`: "Verify first".
- Use `badge` for a count that needs attention, such as unread or pending items, not for marketing.

## Accessibility

Selected destinations expose their selected state. Hidden drawer items are removed from the focus order.
