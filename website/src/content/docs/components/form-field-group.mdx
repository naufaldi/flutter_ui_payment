## Usage

```dart
// example/lib/screens/gallery_forms.dart
PaymentFormFieldGroup(
          legend: 'Disabled group',
          disabled: true,
          children: [
            PaymentTextField(label: 'Name'),
            PaymentTextArea(label: 'Notes'),
          ],
        );
```

## Stripe → kit

| Stripe | Kit |
| --- | --- |
| legend | legend |
| disabled | disabled scope |
| layout | Axis.vertical / Axis.horizontal |

Vertical or horizontal. Nothing else exists. Horizontal falls back below 360 dp or at large text. Disabled scope prevents re-enabling individual fields. Mixed required and optional fields add an optional mark. Group errors belong in a PaymentBanner above the group.

## Variants

Variants: legend, legend with description or error. Nothing else exists.

## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| KYC identity groups | legend | Group Personal details separately from Work and address, preserving reading order. |

Use Section for non-form content.

## States

Default, focused, disabled and error. Errors include an icon, text and an edge. Selection controls support hardware keyboards.

## Do and don't

**Do**: Group Personal details separately from Work and address, preserving reading order.

**Don't**: Use a visual heading without field-group semantics.

## Content guidelines

Use short, specific labels and explain how to correct an error.

Group Personal details separately from Work and address, preserving reading order.

## Accessibility

Input text is 16 dp. Legends precede fields in reading order. Labels and errors stay in semantics when visually hidden. Pickers restore focus.
