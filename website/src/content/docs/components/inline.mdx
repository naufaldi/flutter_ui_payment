
## Variants

Variants: nine text roles; regular, semibold, bold.

### Text roles

Use `title` for a page title, `heading` for headings and subheadings, `body` for running text (semibold for emphasis), `caption` for supporting text and `tag` for a short label above a heading. Payment totals and entered amounts use amountLarge; the single screen amount uses display.

## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| Amount label with supporting copy | body | Use the nine PaymentType roles and semantic text colors. |

Use Amount text for currency formatting.

## States

Inline text displays its supplied content and type role. It has no loading or interaction state.

## Do and don't

**Do**: Use the nine PaymentType roles and semantic text colors.

**Don't**: Invent lead/kicker roles or raw font sizes.

## Content guidelines

Use the role for the text's place in the hierarchy. Use `AmountText` when the value needs currency formatting.

## Accessibility

Preserve reading order and allow text to wrap. Use text labels rather than color alone to communicate status.
