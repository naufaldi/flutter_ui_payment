## Variants

Variants: nine text roles; regular, semibold, bold. Nothing else exists.

### Stripe font roles

| Stripe | Kit role |
| --- | --- |
| title | title |
| subtitle, heading, subheading | heading |
| lead, body | body |
| bodyEmphasized | body with semibold |
| caption | caption |
| kicker | tag |

Payment totals and entered amounts use amountLarge; the single screen amount uses display. These payment roles have no Stripe equivalent.

## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| Amount label with supporting copy | body | Use the nine PaymentType roles and semantic text colors. |

Use Amount text for currency formatting.

## States

Layout and inline text are passive. Images preserve a loading surface and recover from decode failures. Copy feedback stays with the value.

## Do and don't

**Do**: Use the nine PaymentType roles and semantic text colors.

**Don't**: Invent lead/kicker roles or raw font sizes.

## Content guidelines

Use short payment labels and synthetic references in examples.

Use the nine PaymentType roles and semantic text colors.

## Accessibility

Keep reading order aligned with layout. Decorative glyphs are excluded from semantics. Images require alt text; copy actions have labeled targets and confirmation.
