Group payment preferences with PaymentFormFieldGroup sections such as Notifications, Payments and Language. Do not use one flat list. Save is the primary action and locks repeat taps while its Future runs. The host owns values, persistence and statusMessage; status is announced in the header. Avoid another primary action in child.

## Usage

```dart
PaymentSettingsView(title: 'Payment settings', onSave: () async {}, child: const Text('Group settings with PaymentFormFieldGroup'));
```

## States and content

The host supplies state and callbacks. Explain empty states and offer a next action. Use specific labels that wrap. Keep one primary action; separate destructive actions. Use semantic tokens and status text alongside visual marks.

## Accessibility

Labels wrap at large text. Controls retain their keyboard and screen-reader behavior. The host owns navigation and side effects.
