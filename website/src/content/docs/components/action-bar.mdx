## Usage

```dart
// example/lib/screens/flow_screen.dart
// The summary already shows the total, so the bar holds only the action.
PaymentActionBar(
      action: PaymentButton(
        label: s.reviewAndPay,
        busy: c.quoting,
        busyLabel: PaymentLocalizations.of(context).updatingTotal,
        onPressed: quote != null && c.selectedMethod != null && !c.quoting
            ? c.reviewOrder
            : null,
      ),
    );
```

## Variants

Variants: ready, updating, disabled action. Nothing else exists.

## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| Pinned payable total | ready | Use one primary Pay action; updating means the host is recomputing the quote. |
| Total already on screen (checkout summary) | action only, no `total` | The example's checkout: a full-width "Review payment", busy with "Updating total…" during a re-quote, so the total isn't shown three times and the bar stays compact at 200% (D62, #64). |

Use Button group for secondary page actions. Later payment-path screens (confirm, authorize, status, KYC) pin their own action when given a bounded height, so they don't need this bar (D62).

## States

Ready shows the host total and action. Updating keeps the total region stable while the quote changes. A disabled action needs a visible explanation in the checkout content.

**Layout.** The total stays laid out under the "Updating total" caption, so the bar keeps one height while the total refreshes, at every text scale.

## Do and don't

**Do**: Use one primary Pay action; updating means the host is recomputing the quote.

**Don't**: Add another primary Pay in supporting order context.

## Content guidelines

Use sentence case and name the payment fact or action. Keep instructions visible and use semantic type, color and spacing tokens.

Use one primary Pay action; updating means the host is recomputing the quote.

## Accessibility

Preserve reading order, visible labels and semantic descriptions. Interactive targets remain at least 48 dp; status is conveyed in words as well as color.
