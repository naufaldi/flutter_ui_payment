## Usage

```dart
PaymentSection(
  title: 'Account',
  trailing: ActionMenu(entries: [
    ActionMenuEntry(
      label: 'Copy account ID',
      icon: Icons.copy_rounded,
      onSelected: copyId,
    ),
    ActionMenuEntry(
      label: 'Sign out everywhere',
      icon: Icons.logout,
      destructive: true,
      onSelected: signOutEverywhere,
    ),
  ]),
  child: ActionTileGroup(children: [
    ActionTile(
      icon: Icons.receipt_long_outlined,
      title: 'History',
      onTap: openHistory,
    ),
    const ActionTile(
      icon: Icons.pin_outlined,
      title: 'Change PIN',
      disabledReason: 'Managed by your bank app',
    ),
  ]),
);

Future<void> signOutEverywhere() async {
  final ok = await showPaymentConfirmDialog(
    context,
    title: 'Sign out of all devices?',
    message: 'Payments already sent are not affected.',
    confirmLabel: 'Sign out',
    destructive: true,
  );
  if (ok) await host.signOutEverywhere();
}

showPaymentSnackBar(
  context,
  message: 'Reference copied',
  tone: StatusTone.success,
);
```

## Behavior

- `ActionTile` shows an icon, subtitle, disabled reason and an optional destructive tone. A disabled row stays visible with its reason but is not focusable. `ActionTileGroup` puts hairlines between rows.
- `ActionMenu` is built on `MenuAnchor`: arrow keys, Escape and focus return work. Menus open instantly.
- `showPaymentConfirmDialog` resolves to `true` only when the person confirms; dismissing, Back and Escape resolve to `false`. For destructive actions the safe choice receives focus first, so Enter never confirms by accident.
- `showPaymentSnackBar` adds an icon per tone, so the message is not carried by color alone, with an optional undo action.
- `ExpandableSection` is uncontrolled by default (`initiallyExpanded`) and controlled when you pass `expanded` with `onExpandedChanged`. Collapsed content is removed from the tree. Do not use it to hide fees.
- `LoadingSkeleton` is static on purpose. `StateMessage` covers empty, error and no-match states with one action.
