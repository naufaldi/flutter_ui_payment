## Usage

```dart
// example/lib/screens/gallery_layout.dart
PaymentBox(
          stack: PaymentStack.horizontal,
          distribute: PaymentDistribute.spaceBetween,
          alignY: PaymentAlign.center,
          children: [PaymentInline('Total'), PaymentInline('IDR 50.000')],
        );
```

## Variants

Variants: horizontal, vertical, layered.

## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| Group payment facts | vertical | Choose semantic padding and gap tokens; layered is only for deliberate overlap. |

Use Inline for styled text spans.

## States

The box lays out its children; loading, errors and actions belong to those children.

## Do and don't

**Do**: Choose semantic padding and gap tokens; layered is only for deliberate overlap.

**Don't**: Pass raw sizes or invent shadow tokens.

## Content guidelines

Use semantic padding and gap roles to group related payment facts.

## Accessibility

Keep the child order consistent with reading order, including in layered layouts.
