`PaymentTooltip` adds a short hint to a control or a short value: the full date behind "2 days ago", the name of an icon button. It is the theme's ink color with the surface color for text, the strongest contrast the theme has.

## Usage

```dart
PaymentTooltip(
  message: 'Paid on 29 Oct 2026, 14:05',
  child: IconButton(
    icon: const Icon(Icons.info_outline),
    onPressed: showPaymentDetails,
  ),
);
```

On touch screens the tooltip appears on long press. With a mouse it appears after hovering for 500 ms.

## When not to use one

A tooltip is easy to miss on a phone: nothing shows that it is there. It may only repeat or name something already on screen.

- Never put a fee, a requirement, a deadline or an error only in a tooltip. Show it on the page, in an [info row](/components/info-row/) or a [notice banner](/components/notice-banner/).
- Do not put a tooltip on something people tap for another reason and expect them to discover it.

## Content guidelines

- One short sentence or a label, in sentence case, without end punctuation for labels.
- Do not repeat the visible text word for word. Add the detail it leaves out, such as the exact time.

## Accessibility

- The message is also the control's tooltip in the semantics tree, so screen readers read it with the control.
- Keyboard focus opens it. Do not rely on a tooltip for anything a keyboard user needs.

A04 gives the fee policy a real tooltip use, attached to a focusable information button with a 48 dp target.

## Placement, type and timing

The twelve placements are top, topStart, topEnd, bottom, bottomStart, bottomEnd, start, startTop, startBottom, end, endTop and endBottom. Start and end follow direction. A bubble flips when the opposite side fits, then shifts inside an 8 dp margin. Default placement is bottom.

Label names an icon-only trigger; description adds its semantic tooltip. The bubble is never interactive or focusable and needs an Overlay. Hover waits 500 ms by default; keyboard focus opens immediately. Escape, blur, exit, outside tap and another tooltip close it. Long press closes 1.5 seconds after release. Never put a fee, requirement or error only here.
