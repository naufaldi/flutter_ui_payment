`PaymentTooltip` adds a one-line, non-interactive hint to a control or a short value: the full date behind "2 days ago", the name of an icon button. It opens on tap as well as on long press, hover and keyboard focus (D49). It is the theme's ink color with the surface color for text, the strongest contrast the theme has.

## Usage

```dart
// example/lib/screens/gallery_feedback.dart
PaymentTooltip(
          placement: PaymentTooltipPlacement.top,
          message: 'Paid on 29 Oct 2026, 14:05',
          child: Text('2d ago'),
        );
```

An interactive trigger, such as an info button, uses `trigger`. The button's own press toggles the hint, because the button wins the tap:

```dart
// example/lib/screens/steps/fees_step.dart
PaymentTooltip(
  message: s.feesTooltip,
  trigger: (toggle, focusNode) => PaymentIconButton(
    icon: Icons.info_outline,
    tooltip: s.feesInfo,
    focusNode: focusNode,
    onPressed: toggle,
  ),
);
```

## Variants

Variants: label, description; twelve placements. Nothing else exists.

### Tap, one line, and `trigger`

- A tap on a non-interactive `child` (text, an icon, a disabled control) toggles the hint. A second tap, a tap outside and Escape close it.
- A child with its own tap action wins the tap, so wrap an interactive control with `trigger` instead of `child`. The builder receives `toggle` and a `focusNode`. Pass `toggle` to the button's `onPressed` and the focus node to the button. The kit hides the button's own Material tooltip and keeps its name for screen readers.
- An info icon never has a no-op `onPressed`: it toggles its hint or opens a sheet.
- Pass exactly one of `child` and `trigger`.

### Longer explanations open a sheet

A tooltip holds one line. An explanation that needs more, such as a promotion's "Why this?" / "Kenapa ini?", opens a [sheet](/components/sheets/) with a title, the text and one primary Close. See [Promotions](/patterns/promotions/).

### When not to use one

A tooltip is easy to miss on a phone: nothing shows that it is there. It may only repeat or name something already on screen.

- Never put a fee, a requirement, a deadline or an error only in a tooltip. Show it on the page, in an [info row](/components/info-row/) or a [notice banner](/components/banner/).
- Do not put a tooltip on something people tap for another reason and expect them to discover it.

### Placement, type and timing

The twelve placements are top, topStart, topEnd, bottom, bottomStart, bottomEnd, start, startTop, startBottom, end, endTop and endBottom. Start and end follow direction. A bubble flips when the opposite side fits, then shifts inside an 8 dp margin. Default placement is bottom.

Label names an icon-only trigger; description adds its semantic tooltip. The bubble is never interactive or focusable and needs an Overlay. A tap opens it at once, and a second tap closes it. Hover waits 500 ms by default; keyboard focus opens immediately. Escape, blur, exit, an outside tap and another tooltip close it. A hint opened by long press closes 1.5 seconds after release. Never put a fee, requirement or error only here.

## States

Host state is explicit. Loading does not imply success; disabled actions retain a readable explanation. Interactive controls retain focus and pressed feedback.

## Do and don't

**Do**: Attach to a focusable 48 dp trigger; use label only when replacing the trigger name.

**Don't**: Put links or buttons inside tooltip content, or give an info icon a no-op `onPressed`.

## Content guidelines

- One short sentence or a label, in sentence case, without end punctuation for labels.
- Do not repeat the visible text word for word. Add the detail it leaves out, such as the exact time.

Attach to a focusable 48 dp trigger; use label only when replacing the trigger name.

## Accessibility

- The message is also the control's tooltip in the semantics tree, so screen readers read it with the control.
- Keyboard focus opens it. Do not rely on a tooltip for anything a keyboard user needs.

A04 gives the fee policy a real tooltip use: a focusable information button with a 48 dp target that toggles the hint on tap.
