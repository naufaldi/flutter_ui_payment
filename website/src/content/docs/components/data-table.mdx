Settlement statements use host data. Variants: text, link, date, id, status, currency cells; local, offset, cursor pagination. Nothing else exists. Under local paging or no pagination, a host predicate filters rows and sortable columns reorder copies. Under offset/cursor paging, rows are displayed as supplied and sort/page changes call the host. Selection is controlled, and select-all covers the current page. Narrow and large-text layouts collapse to labeled rows. The selection count and batch actions share one line when the actions fit on one line beside the count; otherwise the actions move under the count, so a button label never wraps (D97). Column reorder/resize are not mirrored (D28); legacy flags must remain false and are deprecated until 0.2.0. Stripe batchable maps to selection/onSelectionChanged; loading maps to pending; linkMap maps to column callbacks. No network or destination handling is performed.

          rows: const [],
          rowKey: (r) => '$r',
          pending: true,

### States and content

The host supplies state and callbacks. Explain empty states and offer a next action. Use specific labels that wrap. Keep one primary action; separate destructive actions. Use semantic tokens and status text alongside visual marks.

## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| Settlement selection and sort | local pages | Use offset/cursor callbacks for host pages; never reorder those rows locally. |

Use Table for static fees.

Choose paging by who holds the rows:

| Who holds the rows | Paging |
| --- | --- |
| The host supplied the complete list | Local paging |
| The host fetches one page at a time, with a numeric page position | Offset callbacks |
| The host fetches one page at a time, without a numeric position | Cursor callbacks |

## States

Host state is explicit. Loading does not imply success; disabled actions retain a readable explanation. Interactive controls retain focus and pressed feedback.

## Do and don't

**Do**: Use offset/cursor callbacks for host pages; never reorder those rows locally.

**Don't**: Enable deprecated column reorder or resize flags.

## Content guidelines

Use sentence case and name the payment fact or action. Keep instructions visible and use semantic type, color and spacing tokens.

Use offset/cursor callbacks for host pages; never reorder those rows locally.

## Accessibility

Labels wrap at large text. Controls retain their keyboard and screen-reader behavior. The host owns navigation and side effects.

On phones, select-all has a visible label. The sort trigger names its column and direction; Default order restores host order.

A03 is a searchable settlement statement: local pages select ten rows, sort summaries describe the current order and a secondary batch action prepares the selected synthetic settlements.

Column reorder/resize are not mirrored (D28): phones show a list, and the host configures wide column order and width. The legacy flags and order callback are deprecated and removed in 0.2.0.
