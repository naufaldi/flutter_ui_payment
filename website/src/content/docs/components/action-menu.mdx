## Usage

```dart
PaymentSection(
  title: 'Account',
  trailing: PaymentMenu(entries: [
    PaymentMenuItem(
      label: 'Copy account ID',
      icon: Icons.copy_rounded,
      onSelected: copyId,
    ),
    const PaymentMenuItem(
      label: 'Export history',
      icon: Icons.download_outlined,
      onSelected: null, // shown disabled
    ),
    PaymentMenuItem(
      label: 'Sign out everywhere',
      icon: Icons.logout,
      destructive: true,
      onSelected: confirmSignOut,
    ),
  ]),
  child: accountRows,
);
```

The button shows `Icons.more_vert` by default; pass `icon` for another glyph. Its tooltip, which screen readers also hear, defaults to "More actions"; pass `tooltip` to name the menu.

## Disabled entries

An entry with `onSelected: null` is shown disabled. Keep it in the menu when people would otherwise look for it; leave it out when it never applies to them.

## Destructive entries

`destructive: true` draws the entry's icon and label in the danger tone. Put destructive entries last and confirm them with a [dialog](/components/dialog/).

## Behavior

- Built on `MenuAnchor`: arrow keys move between entries, Escape closes the menu and focus returns to the button.
- The menu opens instantly. A menu used many times a day should not make people wait for it.
- Entries are at least 48 dp tall.

## Content guidelines

- Start each label with a verb: "Copy account ID", "Export history".
- Use sentence case and no end punctuation.
- Keep a menu to a handful of entries. Actions people need on every visit belong on the screen, not in a menu.

## Variants, behavior and migration

Stripe Menu, MenuItem and MenuGroup map to PaymentMenu, PaymentMenuItem and PaymentMenuGroup. Menu onAction receives ids; an item's onSelected takes precedence. Explicit disabled always wins. Put destructive actions in their own final untitled group. Do not place them next to routine actions without a separator. Group titles are headers, not controls. Arrow keys navigate, Escape closes, and focus returns to the trigger. A custom trigger arrives in Phase 3B.

Migration: ActionMenu and ActionMenuEntry remain deprecated aliases until 0.2.0; rename to PaymentMenu and PaymentMenuItem. Old constructors keep compiling.
