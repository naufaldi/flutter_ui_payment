## Usage

```dart
PromoSlot(
  state: offersState, // loading / ready / empty / error
  content: const PromoContent(
    id: 'cb-10',
    kind: PromoKind.sponsored,
    advertiser: 'Bank Contoh',
    title: 'Cashback 10% on bills',
    ctaLabel: 'See offer',
  ),
  onAction: (promo) => host.openOffer(promo.id),
  onDismiss: (promo) => host.hidePromo(promo.id),
  onAbout: (promo) => host.explainPlacement(promo.id),
);
```

## Behavior

- Every promotion is labeled "Sponsored · advertiser" or "Promo", and the label wraps rather than truncates: who paid for a placement must always be visible.
- Empty and failed slots collapse by default (`collapseWhenEmpty`).
- The kit never fetches campaigns, counts impressions, applies discounts or changes a quote. To use an ad network, load its content in your app and pass it in; native-ad SDK views and their policies remain your integration.
- Keep promotions out of the path between the total and the pay button.
- `PromoContent.icon` is accepted but not drawn in the current design.
