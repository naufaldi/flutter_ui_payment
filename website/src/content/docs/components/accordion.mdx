`PaymentAccordionItem` hides secondary detail behind its title: how long a transfer takes, step-by-step payment instructions, buyer protection terms.

## Usage

```dart
// example/lib/screens/gallery_nav_controls.dart
PaymentAccordion(
      children: [
        const PaymentAccordionItem(
          title: 'When will my payment arrive?',
          child: Text('Most transfers arrive within a few minutes.'),
        ),
        const PaymentAccordionItem(
          title: 'Receipt details',
          subtitle: 'Keep a copy for your records',
          media: PaymentIcon(
            Icons.receipt_long_outlined,
            color: PaymentTextColor.secondary,
          ),
          initiallyExpanded: true,
          child: Text('The reference identifies this payment.'),
        ),
        PaymentAccordionItem(
          title: 'Saved method',
          actions: [
            PaymentButton(
              label: 'Edit',
              size: PaymentSize.small,
              width: PaymentWidth.hug,
              variant: PaymentButtonVariant.secondary,
              onPressed: () {},
            ),
            PaymentMenu(
              entries: [
                PaymentMenuGroup(
                  items: [
                    PaymentMenuItem(label: 'View details', onSelected: () {}),
                  ],
                ),
                PaymentMenuGroup(
                  items: [
                    PaymentMenuItem(
                      label: 'Remove method',
                      destructive: true,
                      onSelected: () {},
                    ),
                  ],
                ),
              ],
            ),
          ],
          child: const Text('Bank Contoh •••• 8890'),
        ),
      ],
    );
```

## Variants

Variants: single item, grouped items.

### Uncontrolled

The default. The section keeps its own state. `initiallyExpanded: true` starts it open.

### Controlled

Pass `expanded` with `onExpandedChanged` to own the state, for example to open the section from somewhere else on the screen.

```dart
PaymentAccordionItem(
  title: 'Buyer protection',
  subtitle: 'Provided by the merchant',
  expanded: showProtection,
  onExpandedChanged: (open) => setState(() => showProtection = open),
  child: const Text('Refunds are requested from the merchant.'),
);
```

### Motion

The chevron turns in 150 ms. The body's height eases open in 220 ms and closed in 150 ms, so content below does not jump. Under reduced motion both changes are instant.

### Variants, behavior and migration

Actions allow up to two small hug `PaymentButton`s and one `PaymentMenu`. They sit beside the toggle and do not expand the item. Actions stack below the header under 400 dp or at large text. Keep disabled content readable and fees visible. Use the `media` slot for a `PaymentIcon` or `PaymentImage`.

Migration: ExpandableSection remains a deprecated alias until 0.2.0; rename the constructor to PaymentAccordionItem.

### Layout foundation

PaymentAccordionItem accepts media: a PaymentIcon or PaymentImage. The leading parameter is deprecated; migrate to media: PaymentIcon(icon).

```dart
const PaymentAccordionItem(
  title: 'Transfer details',
  media: PaymentIcon(Icons.info_outline, color: PaymentTextColor.secondary),
  child: Text('Use the virtual account before it expires.'),
);
```

## States

Use `initiallyExpanded` for local expansion state, or pass `expanded` and `onExpandedChanged` to control it from your app. Collapsing the item removes its body from the focus order.

**Layout.** Media and the chevron centre on the title's first line, so a header that wraps at large text keeps them beside the title.

## Do and don't

**Do**: Keep one optional instruction collapsed under its title.

**Don't**: Hide the main Pay action inside a collapsed item.

## Content guidelines

- The title names what is inside, or asks the question it answers: "How to pay", "How long does a transfer take?".
- Never hide fees, the total or anything the person agrees to. The payment summary keeps every fee visible by design.
- Keep the body short. If it needs its own headings, it needs its own screen or [sheet](/components/sheets/).

## Accessibility

- The header is a 48 dp minimum button that reports expanded or collapsed, with a "Show details" or "Hide details" hint.
- Collapsed content is removed from the tree, so Tab and screen readers never reach it.
