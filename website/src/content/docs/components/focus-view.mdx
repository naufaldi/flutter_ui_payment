A report or other focused task presented through existing sheets. Variants: small, large. `showPaymentFocusView(size:)` returns a Future that completes when the view closes; `PaymentConfirmClose` sets the discard confirmation. On phones, including a phone in landscape (window shorter side under 600 dp, D92), it is a bottom sheet: small hugs content, large fills. On tablets it is a side panel 420/720 dp wide. Drag dismiss is disabled so it cannot bypass confirmation. Close, scrim, Escape and Back ask before discarding when confirmClose is supplied. Inline specimens do not block their host route. Both the phone sheet and the wide panel keep the themes around the caller, so a feature-scoped `PaymentTheme` or `PaymentButtonTheme` also styles the panel and its footer buttons.

## Usage

```dart
// example/lib/screens/gallery_views.dart
PaymentFocusView(
                  title: 'Report a problem',
                  confirmClose: PaymentConfirmClose(
                    title: 'Discard report?',
                    message: 'Your changes will be lost.',
                    exitLabel: 'Discard',
                  ),
                  child: PaymentTextArea(label: 'What went wrong?'),
                );
```

## Footer width

The footer stacks its actions at full width, primary on top, whenever the footer is narrower than 600 dp or the text is large. Wider, the actions hug their labels at the end edge.

### States and content

Choose small for a short task and large for a task that needs more room. Phone presentation is a bottom sheet; tablets use a side panel.

## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| Report a transaction problem | small | Use large only for a wider task; confirm close only when the draft is dirty. |

Use Full page view for a destination in the main navigation.

## States

Pass `confirmClose` when a draft has unsaved changes. A failed submit should preserve the draft so the person can correct or retry it.

## Do and don't

**Do**: Use large only for a wider task; confirm close only when the draft is dirty.

**Don't**: Log report text or keep a clean sheet behind a discard prompt.

## Content guidelines

Name the task and its completion action. Explain what will be lost when asking the person to discard a draft.

## Accessibility

Close, Back, Escape and scrim dismissal use the same discard confirmation when supplied. Labels wrap at large text.
