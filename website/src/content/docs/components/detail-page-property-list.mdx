Transaction facts with optional linked values and subText. Variants: vertical, horizontal; pending, ready, empty, error. Nothing else exists. Stripe values map to PaymentDetailValue text or link with optional subText; extraActions are links in an overflow dropdown. A failed module uses warning tone because it is secondary content. The host owns retry, Create and link destinations. Empty messages explain why and offer an action.

## Usage

```dart
// example/lib/screens/gallery_views.dart
PaymentDetailPagePropertyList(
            title: 'Merchant',
            pending: false,
            items: [
              const PaymentDetailProperty(
                label: 'Name',
                values: [PaymentDetailValue('Toko Contoh')],
              ),
              PaymentDetailProperty(
                label: 'Support',
                values: [
                  PaymentDetailValue.link(
                    PaymentLink(
                      label: 'Help centre',
                      external: true,
                      onPressed: () {},
                    ),
                  ),
                ],
              ),
            ],
          );
```

## Variants

Variants: vertical, horizontal; pending, ready, empty, error. Nothing else exists.

### States and content

The host supplies state and callbacks. Explain empty states and offer a next action. Use specific labels that wrap. Keep one primary action; separate destructive actions. Use semantic tokens and status text alongside visual marks.

## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| Merchant facts | vertical | Use a link-only value for support; place the module directly in DetailPage. |

Use Detail page table for repeated attempts.

## States

Host state is explicit. Loading does not imply success; disabled actions retain a readable explanation. Interactive controls retain focus and pressed feedback.

## Do and don't

**Do**: Use a link-only value for support; place the module directly in DetailPage.

**Don't**: Wrap a titled property module in another titled module.

## Content guidelines

Use sentence case and name the payment fact or action. Keep instructions visible and use semantic type, color and spacing tokens.

Use a link-only value for support; place the module directly in DetailPage.

## Accessibility

Labels wrap at large text. Controls retain their keyboard and screen-reader behavior. The host owns navigation and side effects.

A single link-only value centers with its label; at large text it wraps.
