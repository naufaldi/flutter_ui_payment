`PaymentCheckbox` lets people agree to something or opt in, such as saving a card. The box, the label and the description form one row that toggles on a tap anywhere.

## Usage

```dart
PaymentCheckbox(
  value: saveCard,
  onChanged: (v) => setState(() => saveCard = v),
  label: 'Save this card for next time',
  description: 'Stored by your payment provider',
);
```

The checkbox is controlled: keep `value` in your state and rebuild with the new value in `onChanged`.

## Checked and unchecked

A checked box is filled with the accent and shows a check mark in `onAccent`. An unchecked box has a 2 px edge in the 3:1 `border` color, so it stays visible on any surface.

## Disabled

Pass `onChanged: null`. The label turns muted, the box uses the `disabled` color, and taps do nothing. Pass `disabledReason`; it replaces `description` while the row is disabled.

```dart
const PaymentCheckbox(
  value: false,
  onChanged: null,
  label: 'Use as default card',
  disabledReason: 'Save the card first',
);
```

## Content guidelines

- Write the label as the full thing people agree to: "Save this card for next time", not "Save".
- Write it so checking means yes. Avoid negatives such as "Don't send receipts".
- Use the description for a consequence or a detail, not for terms that must be read; link those separately.
- For a setting that takes effect at once, use a [switch](/components/switch/) instead.

## Accessibility

- The whole row is one target of at least 48 dp and one screen-reader node that reads the label, the description and the checked state together.
- The painted box takes no focus of its own, so one Tab reaches the row and Space toggles it. Keyboard focus draws the kit's [focus ring](/foundations/focus/).
- The box centers on the label's first line, so it stays beside the label when the label wraps at large text.

## Pattern adoption

Used in `VerificationIntro` for consent and `PaymentConfirmation` for changed-total approval. Both use the same 48 dp row and 20 dp mark slot, aligned with the section gutter. The consent sentence uses the label role and wraps at large text.

## Behavior, states and migration

Stripe indeterminate paints a dash and announces mixed. It ignores value and reports true when tapped, supporting select-all controls. Error text adds a danger icon, text and an unchecked danger edge. Required is spoken; the host still gates submission. HiddenElements hides label, description or error visually while retaining them in semantics. Do not rely on color alone or hide the only visible recovery instruction.
