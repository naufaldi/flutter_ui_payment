Entry point for external bank sign-in. Variants: ready, host error. Nothing else exists. D32: no credential inputs and no free widget slot. The widget test asserts no EditableText anywhere in its subtree with all slots filled. Brand accepts only PaymentImage or PaymentIcon. Supplemental learnMore content opens separately in FocusView and is outside that guarantee. A host error takes focus and is announced. The host handles sign-in, destinations and legal links.

## Usage

```dart
PaymentSignInView(primaryAction: PaymentButton(label: 'Continue with bank app', onPressed: () {}));
```

Labels wrap at large text. Controls retain their keyboard and screen-reader behavior. The host owns navigation and side effects.

Learn-more is a disclosure row with an information icon and chevron. The brand icon aligns with the heading.
