## Usage

```dart
PaymentChip(label: 'Currency', value: 'IDR');
```

## Stripe → kit

| Stripe | Kit |
| --- | --- |
| onClose | separate remove target |
| onDropdown | editable body |
| onAddSuggestion | suggested body |
| direction | ChipList.reverse |

Callbacks select static, removable, dropdown or suggested kinds. Nothing else exists. Removal uses a separate 48 dp action; suggested chips have a dashed edge. Multiple values summarize the first two labels plus a count. Arrow keys move between chip targets.

## Variants

Variants: label, label with value, removable. Nothing else exists.

## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| Active history status filter | removable | Close clears that filter only; keep status choices as text tabs. |

Use Badge for non-interactive status.

## States

Empty, selected, disabled and error states use semantic tokens. Search additionally supports loading and no matches.

**Layout.** The label centres in the 48 dp box with 16 dp side padding, and icons centre on their line. When the label and value cannot share one line (large text, long values), the pill becomes a rounded rectangle with the control radius, so text never runs into a curved end. The remove target stays 48 dp.

## Do and don't

**Do**: Close clears that filter only; keep status choices as text tabs.

**Don't**: Use chips as a replacement for status-filter tabs.

## Content guidelines

Use short labels and compact localized values.

Close clears that filter only; keep status choices as text tabs.

## Accessibility

Targets are at least 48 dp. Pickers restore focus; result counts announce without platform calls. Keyboard navigation preserves Tab traversal.
