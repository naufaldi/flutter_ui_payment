| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| Status or action mark | medium | Choose the semantic size token; text still communicates the outcome. |

Use Image for host artwork.

## States

The icon displays the selected glyph, size and semantic color. It does not determine payment status.

## Do and don't

**Do**: Choose the semantic size token; text still communicates the outcome.

**Don't**: Assign a raw color that bypasses semantic tone.

## Content guidelines

Choose an icon that agrees with the adjacent label. Keep status meaning in words as well as the glyph.

## Accessibility

Decorative icons are excluded from semantics. An icon-only action needs an accessible label or tooltip.
