`InfoRow` is a label and value pair: a fee and its amount, a reference and its number, a deadline and its countdown. Rows stack into the property lists of summaries, receipts and transaction details.

## Usage

```dart
// example/lib/screens/gallery_kit.dart
InfoRow(label: 'Total', value: AmountText(Money.idr(104000)));
```

## Variants

Variants: plain, emphasis, caption, trailing action. Nothing else exists.

### Emphasis

`emphasis: true` sets the label in the heading style, for a "Total" row.

```dart
InfoRow(
  label: 'Total',
  value: AmountText(quote.total, variant: AmountTextVariant.total),
  emphasis: true,
);
```

### With a trailing action

`trailing` puts an action after the value, such as a 48 dp copy button. Label and value keep the top line, and the action centers against them.

```dart
InfoRow(
  label: 'Reference',
  valueText: attempt.attemptId,
  trailing: IconButton(
    tooltip: 'Copy',
    icon: const Icon(Icons.copy_outlined),
    onPressed: () => copy(attempt.attemptId),
  ),
);
```

### Long values

At normal text size the value keeps its natural width up to 60% of the row, and the label wraps in the rest. A short label never squeezes a file name or reference into breaking mid-word. `AmountText` values always keep their natural width.

For names and references whose start and end both matter, use `MiddleEllipsisText` as the value. It keeps the extension plus a few characters before it, and elides the middle: `ktp_demo_ret…ake.png`.

```dart
InfoRow(
  label: 'File',
  value: MiddleEllipsisText(document.fileName),
);
```

### Large text

Above 1.5× text, label and value still share a line when they fit. When they do not, the value starts the next line at the left edge. Short rows stay one line, and nothing overflows.

Use Property list for a group of facts.

## States

Host state is explicit. Loading does not imply success; disabled actions retain a readable explanation. Interactive controls retain focus and pressed feedback.

## Do and don't

**Do**: Reserve emphasis for the total; captions explain a fact and trailing copy delegates to the host.

**Don't**: Render every value in display typography.

## Content guidelines

- Labels are short nouns in sentence case: "Service fee", "Payment reference".
- Keep values as the host gave them. Do not shorten references yourself; let `MiddleEllipsisText` do it, so screen readers still get the whole value.

Reserve emphasis for the total; captions explain a fact and trailing copy delegates to the host.

## Accessibility

- Label, caption and value are merged into one screen-reader node, read in order.
- `MiddleEllipsisText` gives screen readers the full text, not the elided one.
