## Usage

```dart
// example/lib/screens/gallery_forms.dart
PaymentDateRangePicker(
          label: 'Date range',
          value: null,
          enabled: false,
          onChanged: (_) {},
          firstDate: DateTime(2020),
          lastDate: DateUtils.dateOnly(DateTime.now()),
        );
```

## Stripe → kit

| Stripe | Kit |
| --- | --- |
| value | PaymentDateRange |
| presets | PaymentDatePreset in a sheet |
| granularity | PaymentDateGranularity tabs |
| timeZone / PartialDateRange | host zone / complete ranges only |

Presets live in a kit sheet before the calendar; "Custom range" is a radio row on the presets' text column. Partial ranges and timeZone are not mirrored. The host owns zone interpretation. Granularity tabs remain below the trigger. fromPreset preserves the named range. formatDateRange produces shared localized text for fields and chips.

**Range calendar (D51).** A full-height sheet with a scrolling list of months from `firstDate` to `lastDate`, opened at the range's start or today. The first tap sets the start, the second the end; a tap before the start, or after a complete range, starts again. The range is shown in the accent: filled circles on its ends and a band between them. "Type dates" in the header swaps the calendar for two typed date fields (start on or before end, both in range). The pinned footer shows the range (or "Choose an end date"), a full-width "Apply" that is enabled once a start exists (a start alone applies a one-day range) and a quiet "Clear" that reports `null`. Pass `lastDate: today` for history, so future days are disabled.

## Variants

Variants: preset, custom range; day, week, month, year granularity. Nothing else exists.

## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| History period | preset | Offer last seven days and month presets; custom range handles other periods. |

Use Date field for a single birthday.

## States

Empty, selected, disabled and error states use semantic tokens. In the calendar, days outside `firstDate`–`lastDate` are disabled and today has a ring.

## Do and don't

**Do**: Offer last seven days and month presets; custom range handles other periods.

**Don't**: Convert zones or infer host reporting boundaries in the kit.

## Content guidelines

Use short labels and compact localized values.

Offer last seven days and month presets; custom range handles other periods.

## Accessibility

Targets are at least 48 dp. The sheets return focus to the trigger. Each day is read as its full date with its state ("Monday, 5 October 2026, selected, range start"); arrow keys move by a day or a week and Enter picks. The footer summary is a live region. Weeks start on Monday in Indonesian and Sunday in English.
