Pick provinces or banks from a long list. On a phone (window shorter side under 600 dp, in either orientation, D92) the field is a trigger that opens a full-height search sheet; on a tablet it is an inline field with a floating list (D50).

## Usage

```dart
// example/lib/screens/gallery_forms.dart
PaymentSearchField<String>(
          label: 'Province',
          options: const [],
          selected: null,
          onSelected: (_) {},
          errorText: 'Choose a province',
        );
```

## Stripe → kit

| Stripe | Kit |
| --- | --- |
| data | options |
| defaultValue | initialQuery |
| multiple | PaymentSearchField.multiple |
| onSearch | onQueryChanged |

Use the combobox for selecting values; PaymentTextField.search filters a host list. Local filtering folds common Latin diacritics. onQueryChanged delegates searching to the host and accepts replacement options; new options and `loading` reach an open sheet. Arrow keys navigate, Enter selects, Escape closes. Counts announce through a live region. Multiple selections render removable chips under the field.

**Phones (D50).** Tapping the field, or Enter or Space on it, opens a full-height sheet: the label and close on top, a focused search field, then 48 dp result rows above the keyboard. A single choice closes the sheet. Multiple selection keeps a draft, with its chips and a full-width Done in the footer; close discards the draft, as `PaymentSelect.multiple` does. Focus returns to the field. Focusing the field from code (for example the form's first error) never opens the sheet.

**Wide screens.** The field stays inline and the list floats under it in an overlay with the surface fill, the control edge and elevation, so the page doesn't move. Any edit clears a single selection; clearing the text clears multiple selections.

## Variants

Variants: single, multiple. Nothing else exists.

## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| Province from 38 host options | single | Use multiple only for a set of values; preserve host option IDs and focus first error. |

Use TextField.search to filter history without selecting an option.

## States

Empty, selected, disabled and error states use semantic tokens. Search additionally supports loading and no matches.

**Layout.** Result rows are at least 48 dp with text on a 16 dp inset: the field's text edge in the floating list, the sheet gutter in the phone sheet. The loading and no-matches rows keep a 12 dp gap between the spinner or icon and the text.

## Do and don't

**Do**: Use multiple only for a set of values; preserve host option IDs and focus first error.

**Don't**: Submit the typed province label without choosing a host value.

## Content guidelines

Use short labels and compact localized values.

Use multiple only for a set of values; preserve host option IDs and focus first error.

## Accessibility

Targets are at least 48 dp. Pickers restore focus; result counts announce without platform calls. Keyboard navigation preserves Tab traversal.

Pass an optional `focusNode` to focus the search after form validation. The host retains ownership of that node.
