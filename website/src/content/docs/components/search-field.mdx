## Usage

### Minimal

```dart
import 'package:flutter/material.dart';
import 'package:rakit_ui/rakit_ui.dart';

void main() => runApp(
  const MaterialApp(
    localizationsDelegates: [PaymentLocalizations.delegate],
    home: ProvincePicker(),
  ),
);

class ProvincePicker extends StatefulWidget {
  const ProvincePicker({super.key});

  @override
  State<ProvincePicker> createState() => _ProvincePickerState();
}

class _ProvincePickerState extends State<ProvincePicker> {
  String? _selected;

  @override
  Widget build(BuildContext context) => Scaffold(
    appBar: AppBar(title: const Text('Choose a province')),
    body: Padding(
      padding: const EdgeInsets.all(16),
      child: PaymentSearchField<String>(
        label: 'Province',
        options: const [
          PaymentSearchOption(value: 'barat', label: 'Jawa Barat'),
          PaymentSearchOption(value: 'timur', label: 'Jawa Timur'),
        ],
        selected: _selected,
        onSelected: (value) => setState(() => _selected = value),
      ),
    ),
  );
}
```

## Stripe → kit

| Stripe | Kit |
| --- | --- |
| data | options |
| defaultValue | initialQuery |
| multiple | PaymentSearchField.multiple |
| onSearch | onQueryChanged |

Use the combobox for selecting values; PaymentTextField.search filters a host list. Local filtering folds common Latin diacritics. onQueryChanged delegates searching to the host and accepts replacement options; new options, `loading` and `errorText` reach an open sheet. Arrow keys navigate, Enter selects, Escape closes. Counts announce through a live region. Multiple selections render removable chips under the field.

**Phones.** Tapping the field, or Enter or Space on it, opens a full-height sheet: the label and close on top, a focused search field, then 48 dp result rows above the keyboard. A single choice closes the sheet. Multiple selection keeps a draft, with its chips and a full-width Done in the footer; close discards the draft, as `PaymentSelect.multiple` does. Focus returns to the field. Focusing the field from code (for example the form's first error) never opens the sheet.

**Wide screens.** The field stays inline and the list floats under it in an overlay with the surface fill, the control edge and elevation, so the page doesn't move. Any edit clears a single selection; clearing the text clears multiple selections.

Use TextField.search to filter history without selecting an option.

## States

Empty, selected, disabled and error states use semantic tokens. Search additionally supports loading and no matches.

**Host search errors.** An `errorText` shows the host's explanation above the open phone sheet's results in the danger tone, announced through a live region. Options remain selectable by tap and keyboard, including when the error is local validation. When there are no visible options, the error suppresses the no-matches message. With `onQueryChanged` supplied, Retry (Coba lagi in Indonesian) re-sends the sheet's current query through that callback. The host clears `errorText` when starting another lookup and updates `loading` and `options` as usual. Without a query callback, the error is still readable and there is no Retry action. Pass only safe, user-facing error text; network requests and recovery stay in the host.

<Aside type="caution" title="Unreleased: available on main, not in 0.1.0">
In `rakit_ui` 0.1.0 on pub.dev, `errorText` shows on the field but does not reach the open phone sheet, and the sheet has no Retry (D113). Use a [git dependency](/start/installation/#development-git-dependency) on `main` to try it before the next release.
</Aside>

**Layout.** Result rows are at least 48 dp with text on a 16 dp inset: the field's text edge in the floating list, the sheet gutter in the phone sheet. The loading and no-matches rows keep a 12 dp gap between the spinner or icon and the text.

## Do and don't

**Do**: Use multiple only for a set of values; preserve host option IDs and focus first error.

**Don't**: Submit the typed province label without choosing a host value.

## Content guidelines

Use short labels and compact localized values.

## Accessibility

Targets are at least 48 dp. Pickers restore focus; result counts announce without platform calls. Keyboard navigation preserves Tab traversal.

Pass an optional `focusNode` to focus the search after form validation. The host retains ownership of that node.
