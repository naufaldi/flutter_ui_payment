## Usage

```dart
// example/lib/screens/gallery_forms.dart
PaymentSearchField<String>(
          label: 'Province',
          options: const [],
          selected: null,
          onSelected: (_) {},
          errorText: 'Choose a province',
        );
```

## Stripe → kit

| Stripe | Kit |
| --- | --- |
| data | options |
| defaultValue | initialQuery |
| multiple | PaymentSearchField.multiple |
| onSearch | onQueryChanged |

Use the combobox for selecting values; PaymentTextField.search filters a host list. Local filtering folds common Latin diacritics. onQueryChanged delegates searching to the host and accepts replacement options. Any edit clears a single selection; clearing the text clears multiple selections. Arrow keys navigate, Enter selects, Escape closes. Counts announce through a live region. Multiple selections render removable chips.

## Variants

Variants: single, multiple. Nothing else exists.

## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| Province from 38 host options | single | Use multiple only for a set of values; preserve host option IDs and focus first error. |

Use TextField.search to filter history without selecting an option.

## States

Empty, selected, disabled and error states use semantic tokens. Search additionally supports loading and no matches.

## Do and don't

**Do**: Use multiple only for a set of values; preserve host option IDs and focus first error.

**Don't**: Submit the typed province label without choosing a host value.

## Content guidelines

Use short labels and compact localized values.

Use multiple only for a set of values; preserve host option IDs and focus first error.

## Accessibility

Targets are at least 48 dp. Pickers restore focus; result counts announce without platform calls. Keyboard navigation preserves Tab traversal.

Pass an optional `focusNode` to focus the search after form validation. The host retains ownership of that node.
