## Choosing a component

- Label/value facts → [Property list](/components/property-list/).
- Comparing rows with shared columns → [Table](/components/table/) for static content; [Data table](/components/data-table/) for paging, selection and sorting.
- Action → [Button](/components/button/) for one primary per view; [Link](/components/link/) for inline/navigation; [Icon button](/components/icon-button/) for icon-only actions with a tooltip.
- Short status → [Badge](/components/badge/). A page message → [Banner](/components/banner/). Action feedback → [Toast](/components/toast/).

Colors, spacing, radius and type come only from `PaymentTheme`, `PaymentSpace`, `PaymentRadius` and `PaymentType`; there are no raw values. See [Not in the kit](/reference/not-in-the-kit/) for D28 omissions.
