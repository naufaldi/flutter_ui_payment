## Usage

```dart
// example/lib/screens/gallery_charts.dart
ChartModule(
            title: 'Spending, this month vs last month',
            state: ChartState.ready,
            showHeadline: false,
            height: kind == 'meter' ? null : 180,
            chart: chart,
          );
```

## Variants

Variants: ready, loading, empty, error. Nothing else exists.

## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| Monthly spending | ready | The host supplies headline and chart state; retry repeats only the chart request. |

Use Overview page to arrange several modules.

```text
What does the host know?
├─ Request pending → loading
├─ Failed request → error with retry
├─ No readings → empty with explanation
└─ Readings available → ready with chart
```

## States

The headline block reserves a caption line only when you pass `headlineCaption` or `delta`, so a bare amount sits right above the chart's value band. Above 1.5× text the plot height is capped at `compactHeight`; heights stay identical across loading, error, empty and ready. The one exception is a ready multi-series line or bar chart whose value label stacks each series name over its value: the plot area grows by those extra lines so the plot itself keeps its height. Loading keeps the module heading and chart shape. Empty explains the absence of readings; error offers host retry. Ready requires a chart and uses only the supplied headline.

## Do and don't

**Do**: The host supplies headline and chart state; retry repeats only the chart request.

**Don't**: Compute ledger totals inside the chart widget.

## Content guidelines

Use sentence case and name the payment fact or action. Keep instructions visible and use semantic type, color and spacing tokens.

## Accessibility

Preserve reading order, visible labels and semantic descriptions. Interactive targets remain at least 48 dp; status is conveyed in words as well as color.
