## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| Virtual account number | code | Use a reference display with a host copy action; pre preserves line breaks. |
| Transaction ID in a row | not `PaymentCode` | Use `InfoRow` or a property list item with `reference: true` and a copy button (D57). |

Use Amount text for money. `PaymentCode`'s filled block is for multi-line technical text such as webhook payloads and debug output, plus the large VA number with its emphasis. A reference or ID inside a row uses `reference: true` on the row instead (D57).

## States

Layout and inline text are passive. Images preserve a loading surface and recover from decode failures. Copy feedback stays with the value.

## Do and don't

**Do**: Use a reference display with a host copy action; pre preserves line breaks.

**Don't**: Send the identifier to a transport from the component.

## Content guidelines

## Accessibility

Keep reading order aligned with layout. Decorative glyphs are excluded from semantics. Images require alt text; copy actions have labeled targets and confirmation.
