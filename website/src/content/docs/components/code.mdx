## Usage

```dart
// example/lib/screens/gallery_content.dart
PaymentCode('TRX-DEMO-42');
```

## Variants

Variants: code, pre, samp, kbd.

## Which variant when

| Situation | Variant / composition | Payment example |
| --- | --- | --- |
| Virtual account number | code | Use a reference display with a host copy action; pre preserves line breaks. |
| Transaction ID in a row | not `PaymentCode` | Use `InfoRow` or a property list item with `reference: true` and a copy button. |

Use Amount text for money. `PaymentCode`'s filled block is for multi-line technical text such as webhook payloads and debug output, plus the large VA number with its emphasis. A reference or ID inside a row uses `reference: true` on the row instead.

## States

The code display renders the supplied reference or technical text. A host copy action reports its own success or failure.

## Do and don't

**Do**: Use a reference display with a host copy action; pre preserves line breaks.

**Don't**: Send the identifier to a transport from the component.

## Content guidelines

Preserve the reference exactly. Use synthetic identifiers in examples and keep credentials out of technical samples.

## Accessibility

Provide a descriptive label for copy actions. Long code wraps by default or scrolls within the block when `noWrap` is set.
