`PaymentBadge` names the state of one thing, such as a pending payment or a refund, with an icon, a short label and a tone. The label carries the meaning; the tone only supports it.

## Usage

```dart
const PaymentBadge(
  tone: StatusTone.warning,
  icon: Icons.schedule,
  label: 'Pending',
);
```

The badge sizes to its content. Put badges in a `Wrap` when there can be more than one, as `TransactionListItem` does for an unsettled payment and its refund.

## Tones

`StatusTone` has five values. Each one picks a foreground and container pair from [`PaymentTheme`](/foundations/color/).

| Tone | Use it for |
| --- | --- |
| `neutral` | A state with no judgement: draft, canceled by the customer, unavailable. |
| `info` | Something to know that needs no action. |
| `success` | A settled, confirmed result your host reported. |
| `warning` | Waiting, or a result not known yet. |
| `danger` | Failed, rejected or expired. |

Never pick `success` from what the UI saw (an upload finished, a button was pressed). Use it only when your host's snapshot says so.

## Content guidelines

- One or two words in sentence case: "Pending", "Refunded", "Not confirmed".
- Pick an icon that agrees with the word. The icon and the label are what make the status readable without color.
- Do not put amounts or dates in a badge. Use an [info row](/components/info-row/).

## Accessibility

- Icon, label and tone are three signals, so the status never depends on color alone.
- Tone foregrounds are contrast-checked: at least 5.8:1 on white in light mode and 7.6:1 on `#131417` in dark mode.
- The badge is text: screen readers read its label.

## Migration

`StatusBadge` remains a deprecated alias until 0.2.0. Replace the constructor name with `PaymentBadge`; existing arguments keep compiling.

## Stripe mapping and variants

Stripe neutral, info, positive, negative and warning map to neutral, info, success, danger and warning. Urgent maps to `PaymentBadge.urgent`. Variants: these five tones and urgent. Nothing else exists.

Use urgent only when a person must act now to continue. Use schedule plus “Pending” for a bank wait, and help_outline plus “Not confirmed” when the result is unknown. Do not use a badge as the only failure explanation. Icons scale with text up to 1.6×.
